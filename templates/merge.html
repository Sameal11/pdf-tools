    Why merge and stamp in one step

    Combining files and then numbering or watermarking them separately means uploading the same document twice, to two different tools, and hoping the formatting survives both trips. This tool merges your files and applies page numbers or a watermark to the final combined document in a single pass, so the numbering is always correct across the whole file, not just per original document.

    What order will my files be merged in?

    Files are combined in the order you add them. If you need to reorder, remove a file from the list and re-add it in the order you want, or select all files in the correct order from your file picker at once.

    Does this work with scanned PDFs?
    Yes — merging works on any valid PDF, scanned or text-based. Page numbers and watermarks are added as an overlay, so they don't affect the original scanned content.
    Is there a file size or page limit?
    Uploads are capped at 50MB total per request, which comfortably covers most multi-document merges.
    Are my files stored anywhere?
    No. Files are processed in memory or in a temporary folder and deleted immediately after your merged file is generated.
